# Pune Home clone (Next.js 14 + MongoDB)

Local run:
1. `npm install`
2. Copy `.env.example` to `.env.local` and fill the values
3. `npm run dev` -> open http://localhost:3000
4. Open http://localhost:3000/api/setup once (creates admin + cities)
5. Login at http://localhost:3000/admin/login

Edit brand name/phone/email in `lib/site.js`.
